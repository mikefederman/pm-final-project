    About this demo
    
  
    What it is
    
  
    Batch Retrieval is a backend capability, not a screen. An engineer starts an automated workflow, alone or with collaborators, and the workflow sends one request with 1 to 1,000 part numbers. This page is a stand-in for that workflow so you can see what the backend does with the request.
    
  
    What to try
    
  
    Enter your own BOM (one per line or comma-separated, up to 1,000) or run a pre-loaded batch to see a partial-success response: valid parts come back with their data, and invalid ones are flagged INVALID_PART with no data. Then lower the quota setting and run again to see the 429 error response.
    
  
    What is simulated
    
  
    The backend is a small script in this page. Demo parts PN-00001 to PN-02000 are valid, response time is simulated, and the five part fields are illustrative. Quota values belong to APIM, and security is assumed to be handled by InfoSec. The legacy UI is unchanged.
    
  
    
    

    Demo data only. All research data in this project is simulated. Response time is simulated at 120 ms plus 0.6 ms per part.
